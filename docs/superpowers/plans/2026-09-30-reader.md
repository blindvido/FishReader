# 轻阅 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 完成可启动的 Windows TXT 阅读器。
**Architecture:** WPF 窗口负责阅读与悬停；Core 负责文本解码、书籍状态及 JSON 持久化。
**Tech Stack:** C#、.NET 10、WPF、Win32 光标位置、Windows Forms 托盘。
**Spec:** ../specs/2026-09-30-reader-design.md

## Global Constraints
- 保留原软件和 F:/Fish/moyu，不复制代码或素材。
- 不依赖第三方包；数据只存本机；隐藏周期 40ms。
- 背景透明与字体独立；窗口位置、设置及每本书进度持久化。

## Review Focus
- 中文旧编码：任务 1 检查实际 GB18030 字节解码。
- 损坏配置：任务 1 验证备份与安全回退。
- 文件缩短：任务 1 验证保存字符位置钳制。
- 隐藏后无法返回：任务 2 验证原区域重入恢复和托盘出口。
- 字号/尺寸变化覆盖进度：任务 2 验证重新排版后字符恢复。
