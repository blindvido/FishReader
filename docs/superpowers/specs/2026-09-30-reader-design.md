# 轻阅设计

目标：Windows 本地 TXT 阅读器，逐本保存进度；可调整背景透明度、置顶；摸鱼模式移出隐藏、回到原区域恢复。

分析依据：只读检查 moyuread2 安装目录及 app.asar 的 package.json。版本 2.4.3，Electron 主进程和 preload；依赖 better-sqlite3、chardet、iconv-lite。未运行或完整审计原程序，不复制其代码或素材。F:/Fish/moyu 是旧 Python 原型，缺少进度和单纯悬停恢复功能，保留。

方案：原生 WPF/.NET 10，使用当前机器现有运行时，无第三方包。比改造 Python 原型少 Python/Qt 部署依赖，比 Electron 少浏览器运行时。独立目录 FishReader。

实现：无边框可拖动/调整大小窗口、打开按钮、置顶与摸鱼开关、设置弹窗、状态栏。只读 TextBox 换行阅读；用首个可见字符位置恢复阅读，滚动后 600ms、每 5 秒、切换书籍和退出时保存。JSON 原子替换，损坏文件保留备份；数据默认 LocalAppData/FishReader，可 --data-dir 指定。

编码：UTF-8/BOM、UTF-16 BOM、GB18030 回退。空文件正常展示；读取错误保留当前书籍；限制 32MB 并明确提示。书籍以规范绝对路径区分。

透明：文字保持不透明，仅背景调整 alpha。0% 使用 1/255 alpha 保留 Windows 鼠标命中（视觉近乎透明）。工具栏和状态栏跟随背景；控件使用低调样式。

摸鱼：40ms 轮询全局鼠标物理坐标，用原生窗口矩形判断；移出调用 Hide，隐藏不拦截鼠标，计时器继续运行；移回 Show 且不主动夺取焦点。设置/文件对话框期间暂停检测。关闭摸鱼立即显示。提供托盘恢复，恢复同时关闭摸鱼，避免找不到窗口。最小化不因悬停恢复。

验证：无外部测试包的控制台断言集，实际文件编码/持久化/坏数据/范围检查；WPF STA 集成验证真实滚动恢复、透明画刷、置顶、实际窗口隐藏/恢复。生成 Release 启动文件，交付说明、分析和测试结果。显示缩放、多显示器、透明视觉仍需用户桌面验收。
