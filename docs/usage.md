# 轻阅

Windows 桌面 TXT 阅读器和网页浏览器。支持章节目录、逐章阅读、逐本保存进度、背景透明、置顶、鼠标离开隐藏和 Ctrl+双击唤出。

## 启动

双击发布目录中的 `FishReader.exe`。请保留同目录内的配套文件，也可以整文件夹复制。启动新版前请先退出正在运行的旧版。
需要 Windows 10 1809 或更新版本、.NET 10 Windows Desktop Runtime，以及 Microsoft Edge WebView2 Runtime。

## 使用

1. 点击「打开 TXT」或按 Ctrl+O，也可直接拖入 TXT 文件。
2. 使用滚轮、Page Up / Page Down 或底部箭头翻页；空格下一页，Shift+空格上一页。
3. 阅读进度在停止滚动 600ms 后保存，并每 5 秒、切换书籍、退出时保存。重新打开程序自动恢复上次的书籍。每本书的位置独立保存，以文件绝对路径识别；移动/重命名文件视为新书。
4. 勾选「置顶」，窗口保持在普通窗口上方。
5. 「设置」中选择配色、字号、字体颜色和背景不透明度。「选择颜色…」可打开系统颜色选择器，自由指定文字颜色。0% 为视觉透明，文字仍不透明。为保证 Windows 透明区域可以接收滚轮和点击，0% 实际保留 1/255 的背景 alpha。
6. 勾选「摸鱼」，窗口只保留正文，标题栏、工具栏、章节栏、底栏、滚动条和边框都会隐藏，任务栏也不会出现窗口按钮。鼠标移出窗口后自动隐藏；需要重新显示时，按住 Ctrl 双击原窗口范围内的任意位置即可唤出，悬停不会触发。全局鼠标钩子只观察按键，不拦截或吞掉任何点击。隐藏期间不会阻挡下方程序操作；唤出时不主动抢焦点，移出后会再次隐藏。
7. 拖动顶栏移动窗口；拖动任意边缘或四角自由调整宽高，右下角手柄也保留。最小为 300×260，拖动缩放会保持当前阅读位置并保存窗口尺寸。字号随窗口大小自动缩放。「×」保存退出，「—」最小化；最小化后从任务栏恢复。
8. 找不到窗口时，右键系统托盘的轻阅图标，选择「显示阅读器（关闭摸鱼）」；双击图标也可恢复。

文件选择、章节下拉目录及设置对话框打开期间暂停摸鱼隐藏，拖动调整窗口时也暂停。摸鱼开关会保存；窗口隐藏后按住 Ctrl 双击上次的窗口范围即可唤出，找不到窗口时用托盘恢复。

## 章节与页面

- 工具栏下方的「章节」下拉列表就是目录；选择后只显示当前章节正文。当前选中的标题即当前章节。
- 目录两侧的 ‹ / › 切换上一章、下一章；也可按 Ctrl+Left / Ctrl+Right。章节首尾会禁用对应按钮。
- 读到本章末尾后，再向下滚动、按 Page Down / 空格，或点击底部的下一页按钮，会自动进入下一章。长章节在到达末尾前继续正常翻页。
- 底栏显示「本章 当前页/总页数」和全书进度。TXT 没有固定页码，页数按当前窗口和字号估算，缩放后自动更新。
- 章节下拉栏的背景随背景透明度一起变化，文字保持清晰；展开的目录使用不透明底色，便于选章。
- 自动识别独占一行的常见标题，如「第一章 起点」「第001章」「第2回」「Chapter 3」、序章、楔子和后记。正文前的说明保留为「前言」，没有可识别标题时作为「全文」阅读。
- 非标准标题可能无法识别，也可能将类似标题的正文误判；不会删除或改写源文件。重启继续恢复当前章节内的位置，兼容上一版保存的全文进度。

## 网页浏览

点击顶栏「网页」，输入网址并回车或点「打开」。不写协议时自动使用 https。
地址栏左侧提供后退、前进和刷新；Ctrl+L 选择地址栏，F5 刷新。
网页区域提供「− / 百分比 / +」缩放按钮，范围 25%–200%，点击百分比恢复 100%。验证码或登录弹窗超出窗口时，点击「适应弹窗」缩小到可见范围，无须刷新页面；也可用 − 手动调整，缩放比例会保存。
页面连续跳转时，已取消的旧请求不会再覆盖当前页面状态，也不会把 OperationCanceled 显示为加载失败；真正的网络失败仍会提示。
网页里的新窗口链接会在当前页面打开。点击「返回 TXT」回到原章节和阅读位置。
网页模式同样支持置顶、窗口缩放和摸鱼隐藏；窗口隐藏或返回 TXT 时，网页静音，恢复后解除静音。

上次访问的网址会保存，再次进入网页模式时加载。浏览器缓存和登录状态保存在数据目录的 `WebView2` 子目录，与系统 Edge 的个人资料分开。
默认启用「手机浏览」：使用手机浏览器标识，并随窗口宽度调整网页视口；关闭可恢复 PC 模式，切换时会刷新当前页。网站是否提供专门手机版仍取决于网站自身。
手机模式同时将鼠标按住拖动转换成移动端触摸操作，兼容只响应触摸的手机版滑块；关闭手机模式后恢复普通鼠标输入。
手机布局使用真实网页窗口及原生缩放，不再覆盖设备的屏幕尺寸；验证码等嵌入页面保留自身视口。
默认启用「网页透明」：去掉网页及常见内容容器的底色，跟随阅读器背景。到「设置」把背景不透明度调为 0%，即可获得视觉透明效果；文字仍清晰。关闭开关会恢复网站原底色。
图片、背景图片、视频和画布内的颜色保留；部分网站去掉底色后对比度可能降低，可关闭「网页透明」。网页字体保留网站自己的样式。两个开关都会保存。
如果网页运行环境缺失，地址栏下方会显示错误。可安装微软 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 后重启应用。

## 数据

默认保存到 `%LOCALAPPDATA%/FishReader/state.json`，包含每本书字符位置、窗口大小位置、显示设置和上次网页地址。TXT 阅读不会上传书籍内容；网页模式会连接您打开的网站。
配置使用临时文件写入后替换；损坏的 JSON 会留下 `.corrupt-时间` 副本。保存失败会在底栏显示，退出时提醒。

支持 UTF-8、UTF-16 BOM、UTF-32 BOM，非 UTF-8 文件回退 GB18030。没有 BOM 的 UTF-16 不能可靠自动识别，请另存为 UTF-8。单本上限 32MB；读取大文件期间界面可能短暂停顿。

可用 `FishReader.exe "书籍.txt"` 直接打开，或用 `--data-dir "目录"` 指定独立数据位置。同一个数据目录只允许运行一个实例。

## 开发和验证

需要 .NET 10 SDK。执行 `build.ps1` 编译并发布到 dist。首次构建会从 NuGet 下载微软 WebView2 SDK 及所需 Windows SDK 引用。

```powershell
dotnet run --project Tests/FishReader.Tests.csproj
```

测试包含实际中文解码、原子保存往返、损坏配置、跨实例进度恢复、切书、字号调整、透明画刷与置顶、章节识别/选择/恢复、旧版书签兼容、八向缩放及小窗口排版，以及真实鼠标移出隐藏、按需唤出的窗口可见性。桌面测试会短暂显示测试窗口和移动鼠标，结束时恢复原鼠标位置；需正常交互式桌面权限。

多显示器混合缩放、远程桌面、全屏独占程序之上的显示行为尚未逐一人工验证。
